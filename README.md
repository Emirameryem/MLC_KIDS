# LC Kids — 0–8 Yaş Bebek & Çocuk Giyim Mağazası

**LC Kids** markasının sakin, sıcak ve doğal ruhunu yansıtan tek sayfalık tanıtım web sitesi.

## Özellikler

- **Görsel Kimlik:** Sıcak krem (`#FAF7F2`), sıcak bej (`#EFE7DC`), latte (`#A68966`) ve koyu espresso (`#2C241E`) renk paleti; *Cormorant Garamond* ve *Plus Jakarta Sans* tipografisi.
- **Bölümler:**
  - Şeffaftan buzlu cama dönüşen navigasyon ve dairesel **LC Kids** logosu
  - Tam ekran açılış alanı (*Hero*)
  - Marka hikayesi, kısa tanıtım videosu ve tasarım felsefesi
  - Kaydırma ve sürükleme destekli yatay editoryal lookbook galerisi (*Atmosfer*)
  - Etkileşimli marka değerleri ve paralaks makro kumaş dokuları (*Kumaş & Doku*)
  - Mağaza adresi (*Cumhuriyet Bulvarı, Yaşam AVM Kat: 2, Tatvan / Bitlis*), çalışma saatleri (*Haftanın Her Günü: 10.00 – 21.00*) ve doğrudan iletişim / WhatsApp alanı

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```

Üretim derlemesi için:

```bash
npm run build
```
